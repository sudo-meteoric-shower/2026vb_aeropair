# AeroPair · 航空合成实验室

Pair aircraft parts to explore designs through sketches and real-world aircraft photos. Built with Visual Basic and Windows Forms.

在 Windows 上运行 [航空合成实验室.exe](bin/Release/航空合成实验室.exe)，点击「进入实验室」。先选「向后斜的机翼」，再选「螺旋桨」，点击「合成」即可对照整机简图和 Long-EZ 的实机照片。部件组合和照片均可离线查看。

试试「电动机＋喷气发动机」，可以看到电机与涡扇转轴交换功率的台架试验。「研究原文」打开该组合对应的论文或调查报告。点击配图可放大并查看图片出处。「构型观察」展示实机上可辨认的部件，「设计推想」和「试验设想」保留可继续探索的问题。

用 Visual Studio 打开 [解决方案](航空合成实验室.sln) 可查看和编译源码。项目使用 .NET Framework 4.0。课程设计、操作步骤和案例来源见 [设计说明与操作步骤](设计说明与操作步骤.docx)。
